## 🌌 Overview

Welcome to my portfolio! I am **Rahul Jayakumar**, a B.Tech AI & ML student, specializing in creating intelligent applications and highly immersive web experiences. This portfolio is engineered to deliver a cinematic, dark-themed user journey inspired by Batman/Gotham aesthetics. It blends high-performance React components, smooth glassmorphism UI, and striking 3D WebGL animations.

## ✨ Features

- 🎭 **Immersive Gotham Theme**: A state-of-the-art dark design language that feels premium, mysterious, and engaging.
- 🚀 **Dynamic 3D Animations**: WebGL-powered interactive elements and micro-animations via Three.js and Framer Motion.
- 📱 **Fully Responsive**: Flawless cross-platform execution using an adaptive glassmorphism layout.
- ✉️ **Live Transmission Contact Form**: A fully integrated Web3Forms setup for direct communication—no backend required.
- ⚡ **Optimized Performance**: Built with Vite and React for ultra-fast, seamless navigation.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Modern CSS with Glassmorphism UI
- **Animations**: Framer Motion
- **3D Graphics**: Three.js & React Three Fiber
- **Icons**: Lucide React
- **Forms**: Web3Forms API

## 🚀 Installation & Local Development

Want to run this project on your local bat-computer?

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rahulj-2006/Portfolio_Rahul.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Portfolio_Rahul
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
